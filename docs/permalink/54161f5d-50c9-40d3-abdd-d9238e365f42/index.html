Web Desktops For Young Ladies

11/8/2026

I asked AI to create an operating system in a web page and it did, this is a real operating system well made for web programming.

I glanced at the code the AI generated and it is really nice, everything is well ordered, and tiny so that local AI can understand it.

When I arrived at the problem of learning how to use it, I told the AI to create Visual Basic, Automator, and HyperCard clones.

It is not a linux-like system I told the AI to built on top of Web APIs, to embrace them as the fundamental surface.

In deed I have a terminal inside a web page and I have a dom command, that instead of creating a document object model element created a window.

I do have a sample application that I can pipe into the window, there is a device on the file system that represents the scene as well.

I kept pressing the AI to create things in layers, and never present me with an incomplete system.

It initially game me the terminal, the back window hackers use, so the system was already functional.

That is when said dom “Hello Word” and opened a blank window, inside the browser that had a “Hello World” in the title bar.

I will ask the AI to allow me to hide the caption bar, and maximize windows by default, to pretend it is just a web app.

With minimal effort however, I could create a voice recorder app, and the user can save their voice in the virtual file system.

And synchronize their virtual file system, with a standard Linux file system.

To me this is a test subject for researching local models with small context, but it is an interesting and sturdy starting point for actual Web Desktops.

While AI was building a proper web operating system, an employee of the leading AI company whom I have been calling tito.

Complained that AI is not in good shape yet, that it needs work, that is in fact a mistake, the AI works very well but demands well worn roads.

Every nerd eventually programs an operating system, or muses about it, linux is everywhere, and the Desktop metaphor is well known and well worn.

I had to tell the AI to be careful, to be wise, to create Post Doctoral level code, but the thing that drove this project is a well worn OS/Desktop groove.

And yet we did not create an ordinary OS, we created one, that correctly, uses the browser, and CSS frameworks, and few other things.

Therefore, I present to you Programming by Subtle Analogy, to be wining pattern for the models we have today.
