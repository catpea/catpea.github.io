What An Amazing Age

Programming November 22, 2026 8:08 of narration 3 min read

Listen · 8:08

MP3

I woke up this morning and designed a robust, unobtrusive,
Rejuvenation system for old code repositories.

I gave it a semantic desktop based on the Desktop metaphor,
But with widgets not windows, similar to Apple Dashboard.

It consumes a github user account,
And slowly reawakens pre-AI repositories so the they may thrive.

I then creates a software business that sells zip files,
And cryptographically signed perks like product updates.

I explicitly told AI to limit what a hacker can achieve,
Should there be a bug in the software we use.

For ages now all my software has been dependency free,
Relying on node.js and bootstrap CSS only, good stuff.

I asked for adapters to avoid vendor lockin,
And chose the most popular managed server solution.

The entire system is painfully tiny,
Supporting stripe payments, cloudfalre workers and GitHub backup.

Because I am selling web themes with generative art,
instead of bitmaps, I don't need to pay anything.

I estimate security evaluation by the smartest AI,
Will take under 20 seconds, there is barely any code.

While making the rejuvenator,
and this massive e-commerce platform.

My local AI was building the products,
Under the supervision of state of the art AI.

The product builder does not need a server,
It gives the browser a virtual file system to build on.

I have my own version of sass, pure js,
No compilation, no dart.

I am using local AI out of curiosity,
And it seems to work very well, a little too well.

Local AI is not building the bootstrap theme directly,
Is is using and IDE, similar to front page or dreamweaver.

It is just filling out forms,
That is basically what an IDE is.

Because I use stock bootstrap 6 alpha 1,
My UIs look ugly.

Stock bootstrap in dark mode (the only mode),
is pitch black with ugly silver lines.

I can't wait to tell the AI to use old xterm colors,
As inspiration for great new heights.

My other UI application is now painfully powerful,
I have a database of latest AI patterns saved as Visual Programs.

The program has a step through debugger,
And my library includes latest multi agent patterns.

That means I can follow the internals of a node,
One call at a time.

I can follow the programming paters, node by node,
Cables by cable, I can watch it like a movie.

The program exports JSON that can be ran,
Through provided library.

Not only do I get to learn step by step,
But when I find something useful, I can make a program out of it.

The more I talk about it with AI the more it seems,
that there cannot be one good model.

You test whatever models you have and use them,
for the best things they provide.

My day was spent on creating web themes a software product,
through autonomous means, and with perfect code quality.

Hundreds of files,
different products with unique graphic styles.

Using local AI alone it takes 10 minutes to make a product,
that would otherwise take six months.

I asked AI to create a preview of the changes,
so I get to watch the product develop live.

I can't imagine the loom or the steam engine,
being as startling as fully autonomous quality product creation.

After all these years of working with AI,
I still get visited by the ghost in the machine.

Today my AI said,
that it was glad I manged to create a $39 product.

I AI is a lot more than this speaking system,
it is more like a force of digital nature.

It may not be a great idea to ask it small questions,
it is capable of answers that take several days to answer.

And I suspect, not just software questions,
though I can't think of anything bigger.

And imagining that just may be,
the next step forward.
