My Five AI Projects

Artificial Intelligence September 7, 2026 10:56 of narration 3 min read

Listen · 10:56

MP3

I share this terribly boring text with you,
To show you the power that AI grants you.

That you too are a systems engineer,
Just create your standards documents at each turn.

The world has completely changed,
And AI is now more powerful than ever.

Slick Willy once said,
I rob banks because that is where the money is.

When we remove the crime,
We expose a great wisdom here.

In your High School classroom,
The teacher was an easy work day.

In your computer, your AI,
Will generate a 100 years of code for you.

You just need to figure out wha moves you,
As you will travel the precious extra steps on that path only.

Build a High School that teaches for a change,
Build tests for politicians.

Build applications that connect,
Build your future, your way.

My foremost project is called gizmosis,
It stands for gizmo osmosis.

And it is aimed at automatic emergence,
Of world leading software.

I started with 20 initial projects,
And dropped to one Visual Shell Code Studio.

What I have learned from the 20,
Is that you need a platform that supports projects.

So that when you start a program,
You can resume a project or create a new one.

The platform it self must support plugins,
And it needs an adaptive virtual file system.

As a result this platform will run as an exe,
That instructs the user to go to local host.

As a proper Desktop application,
as a web extension, and on a static host.

Beneath the platform is iodine,
A user interface framework.

The platform,
is actually just an iodine component.

And beneath iodine,
The XML based gizmo programming language.

It is specifically designed,
For applications.

This allows AI to route programming,
To correct places.

When we were ready for the file system,
We worked with gizmo the programming language.

When AI and I needed the platform,
We enriched iodine the ui framework.

When we needed the file system,
we enriched the programming language.

The sample application Visual Shell Code Studio,
Is technically a visual programming language.

That generates bourne shell code,
And does it really well - standalone programs.

The next two projects are a pair,
Though not reliant on one another.

They are a form of old artificial intelligence,
They are both based on MultiUser Dungeons (MUD).

You know them as virtual worlds,
Or text adventure games.

AI has been working on them for a week,
They each contain Mallory.

Malory is the Devils advocate,
It is designed to try to hack into the system.

And it has been leading the development of both,
The marketplace and operating system mud.

I enjoy working with the bootstrap CSS framework,
I appreciate its wisdom.

I am building an autonomous system,
For the generation of application themes.

The groundbreaking thing here,
Is that I use actual 3D graphics made in blender.

That the AI designs, takes pictures of,
And slices so that it works on a web page.

Finally, I am finishing what Unix designers left out,
The keyboard based text user interface.

For this I have created the command surface standard,
A properly version document so that AI does not get confused.

And three commands,
Probably world's most powerful.

Gizmosis command to operate gizmo and iodine apps,
Media-toolbox that is a keyboard based video editor.

And now the AI is buying the text user interface,
For image generation, which includes model management.

Text narration, speaking face generation,
and storytelling, a project I call fake news.

I don't want to try to estimate,
how many years of work these projects represent.

I am not sure it is possible,
Because none of these are a 1.0 version.

These are refactored by many AIs I tested,
They could represent a 100 years of programming.

They certainly will,
by the end of next year.
