My foremost project is called gizmosis, It stands for gizmo osmosis.

What I have learned from the 20, Is that you need a platform that supports projects.

So that when you start a program, You can resume a project or create a new one.

The platform it self must support plugins, And it needs an adaptive virtual file system.

As a result this platform will run as an exe, That instructs the user to go to local host.

As a proper Desktop application, as a web extension, and on a static host.

Beneath the platform is iodine, A user interface framework.

The platform, is actually just an iodine component.

And beneath iodine, The XML based gizmo programming language.

It is specifically designed, For applications.

This allows AI to route programming, To correct places.

When we were ready for the file system, We worked with gizmo the programming language.

When AI and I needed the platform, We enriched iodine the ui framework.

When we needed the file system, we enriched the programming language.
