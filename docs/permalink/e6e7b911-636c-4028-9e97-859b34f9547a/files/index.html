    Every occupied hex holds related code. Enter it and the very same tile remains at the centre, surrounded by its parts. Empty ground is available for construction.

    Click / tap
    Select a tile.
    Double-click / Enter
    Go inside the selected tile.
    Escape / Outside
    Return to the previous view.
    Drag / pinch / wheel
    Pan or zoom the map.
    Q W E / A S D
    NW, NE, E / W, SW, SE.

    Choose one of six adjacent spaces.
    Inhabit, then G
    Walk an agent to the selected tile.
    P / Politics
    Show the process overlay.
    Space / Home
    Pause animation / frame the island.
    Ctrl+Z / Ctrl+Shift+Z
    Undo / redo world edits.

    Heuristics and source paths are illustrative metadata. This game neither analyzes nor executes code. Politics is a small sequence rehearsal, not a BPM engine. XML imports never fetch linked files.
