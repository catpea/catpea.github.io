Desktop Application Development For Young Ladies And Cats

7/28/2026

There is a very sturdy platform named Electron, it is a web browser that you program with JavaScript.

It runs on every desktop operating system, Mac, Linux, and Windows.

You have to look at Electron Fiddle Tool, and check out the Community Showcase.

You have to use AI, the type called coding agent, Claude, Codex, or Grok.

And then you just say: “I want to build an Electron based Desktop Application”.

You can say that you want a Docking Manager, something like dockview, FlexLayout, or golden-layout.

I always tell my AI to create: “a lightweight plain JavaScript version”

But examine the complete programs first, so that you know what features you want to keep.

Then tell your AI to use bootstrap in dark-theme mode, and that you want bootstrap-icons.

I recommend you create a starter template, for all your projects.

Your first dock panes would be project manager, and project template selector.

If you want to practice bootstrap, tell AI to create a bootstrap based docking manager.

Then you just search around the Electron Showcase, until you come up with an idea for an application.

Or you can upload your starter application to github, you then share your starting point with others.

You don’t have to start with an idea, you should always start by building up a trusty base platform.

At any point you can tell your AI, let us start from scratch based on what we have.

Or let us begin work on a 2.0, that is a complete rewrite of what we have.

And though this will set you back, you will wash your application and strengthen it.

No one gets to tell you what you should program first, program what moves you because that will inspire you the most.

But if you do need an idea, a visual programming language is a good start.
