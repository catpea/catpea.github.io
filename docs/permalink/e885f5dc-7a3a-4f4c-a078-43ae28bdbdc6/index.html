Understanding Your Software, For Young Ladies

11/1/2026

In order to fully understand the programs AI generates for you, you have to ask AI to also create a website that explain every feature.

But wait, you should not just keep updating what AI created.

When you negotiate the creation of a program you like. You should ask AI to create a complete rewrite, from ground up.

Based, on the features you have discovered.

Asking your AI to use portable-ish plug-in architecture is useful here, because when you have strong feature divisions a rewrite can be easy.

Furthermore, asking your coding agent to describe your program, and asking the biggest AI you got to rethink it and make it better.

Can create an even stronger beast, often with clearer code, less mess and more power.

And then to regain control over the now much more powerful project, you ask for a website that presents every feature.

That contains documentation for the main application, and any supporting command line commands.

You ask for a tutorial page, a playground page, and several examples.

If you have artistic things, you ask for design galleries, and screenshots.

If you want insight into your plugins, you ask for a README on each plugin.

I want to make this clear, this is not about creating a website, but creating a pleasant information device

One that presents features from different perspectives, from a tutorial, sales, artistic and technical end, to name a few.

As powerful and useful as the website approach is, I still want you to be mindful of asking for a rewrite from ground up.

A single shot rewrite may just be so powerful, that instead of protecting hard earned code.

You may wish to change the style of your programming, to create smaller and decoupled pieces that you can send for regeneration.

Finally, the website perspective is bound to be so clear, that not only do you gain control but also a vision of the better program.

A decade ago, creating a website just to understand a program, was wasteful and ridiculous, is not down right souls sucking.

Today, it is an unusual, but advanced and wise way, of communicating with AI, and staying in-control of your project, no matter how small or large.
