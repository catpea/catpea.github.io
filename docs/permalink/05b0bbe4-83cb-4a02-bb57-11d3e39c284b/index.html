The Visual Programming Twist: No If, Loop, or even Function

8/18/2026

But, it is possible, to branch programs.

Each time a part of a program is executed, it sends an exit code through a port.

And multiple other programs, can be connected to this port.

But the cables have order, and before you start the next, you must reach the end of first.

AI recommended that these cables are optional, and that the order can be calculated based on data fields and their cables.

That is a very big mistake, and I made data cables optional instead.

You are always in control of the sequence, you always get to see it from left to right, and branch down.

I didn’t expect this, but I knew the other visual programming models were broken.

The best program has a split stream of objects into objects, and produce multiple outputs based on object properties, streamed or not.

Powerful, but it takes the power of knowing, where every thing is, away.

The things I connect have loops and streams, deeply hidden away, inside them.

The things I connect together are powerful commands, that load, transform, and produce files.

They can be weird files, queues, sockets, urls, but on the screen to the user they are files.

One of the commands is ffmpeg, that everyone uses for video processing everywhere.

It takes in files and produces more files, but I split it into pieces like Image To Video, or Video To Animation.

The fact that it is ffmpeg is hidden beneath, the functionality you need.

AI can of course create more things you need, my favorites are make a photo talk.

I wrapped an entire AI driven Linux container, with a simple command that I simplify even more.

And the wires or cables I connect to it, is just image and audio.

Because the thousands of lines of code beneath, are not important to visual programming.

The image can be generated by another command, you would connect the output of that command as image input.

But when you zoom out, the data cables fade away, and what you see are the sequence cables the red wires.

Tucked away deep in my program, is one of the world most precious code editors.

Pure ECMA Script modules, Web Component based, no compilation step, lighter than air, more powerful than entire corporations.

But code is not for the surface dwellers, not anymore.

When you create a specialized harness for it, AI is much better at programming than humans.
