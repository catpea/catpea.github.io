Power Programming With Artificial Intelligence

Programming February 22, 2026 9:33 of narration 3 min read

Listen · 9:33

MP3

I’ve been stuck learning,
and re-invenitng Visual Programming for many years.

I have learned things more powerful
than I can imagine.

And I discovered,
that the stinkiest and most confusing hole in a program I ever encounered.

Was so nasty, because the developers,
stuck a text based visual programming language in there – yikes.

AI once called it edge based visual programming language,
OK, I am now four version into my own implementation.

It is going so well, that I send command line commands,
keyboard keystrokes, and entire files and their compression results through it.

I am now free,
I am now complete.

So I have begun walking back through every program that made me dream,
of fixing visual programming so that I could re-write it correctly.

I have narration software, 3D visual programming in VR,
ready for voice recognition and unimaginable applications today.

And today, as I finished my new blogging engine,
again with the use of text based visual programming.

I ordered a $20 AI, that I canceled instantly after signing up,
a month ago, due to its low quality

I ordered it to “study code that I fed it” and create a Mind Mapping program,
that will be used as a web server application behind authentication.

As a desktop application with standard access to the host file system,
and as a web extension that will use the storage technologies there.

Because I fed it existing code, the AI performed flawlessly,
it learned well, and my $20 investment turned to a $20,000 code base.

And folded over several times increasing in value,
as as I integrated it with local AI.

Let me give you an update on AI, they are now learning at geometric rates,
yes, but without the doom – you are the boss now.

The AI no longer makes you 100 times more powerful, as I stated before,
and upset some readers enough to say AI is dumb.

AI now makes you 1,000 times more powerful,
and I suspect do what I just did to local AI, and make it just as smart.

You have to feed it code you appreciate,
to teach it your own dialect of programming.

Allow me to briefly explain, that mind mapping maps out concepts,
for example Web Programming consists of JavaScript, HTML and CSS.

And what I did to ask the geometrically more intelligent AI,
to allow me to select a node in my application and tell the AI to expand it.

You ask AI using a prompt on the screen,
to create a conceptual breakdown of whatever you need.

I am sure it has been done a million time,
but never in an application that belongs to you, that you can sell.

So let me just urge you, with all the might of an amazing screenshot,
you need to learn JavaScript programming and study AI behavior.

The younger you are the more important this is,
unless your school is teaching you more powerful things, learn on your own.

Don’t let schools make a fool out of you, grades are bullshit,
you are getting the same grades in all your classes to control you.

The teachers are copying grades from each other to make them realistic,
and the principal is ensuring no one sticks out to retain school accreditation.

The people on the internet saying AI is a bubble, are the bubble,
and they are about to burst into smithereens.

And those who are saying that programmers are about to be out of a job,
are correct.

The programmers, will now become employers of those who didn’t learn,
how to write computer programs.

Yes, programmers will not be doing the programming,
the way an orchestra conductor does not make the sounds.

Much more than that no one can say,
we know that AI changes a lot.

And a lot of people choose not to predict too much,
becasue it sounds so unhinged.

But we can say one thing,
please learn programming.

Go talk to your AI,
times have changed now.
