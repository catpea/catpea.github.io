The author reflects on why improving AI itself won’t make programming better and instead focuses on using AI to rationally evaluate and extend application panes. The post critiques the limitations of current AI as mere autocomplete, argues that real programming breakthroughs only became feasible with AI‑generated code, and introduces the concept of *Implicit Loops and Logic*—a high‑level command model that sinks complexity into actions rather than scattered loops and conditionals. This approach, combined with a custom code editor integrated into a visual programming shell, enables concise, maintainable scripts (often under 50 lines) and prevents the visual language from devolving into an unreadable “cable‑toy.” The article also warns about the social dynamics of feature pushes and forks, emphasizing that thoughtful AI‑assisted design can manage and enhance the entire ecosystem of the author’s applications.
